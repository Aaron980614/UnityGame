HTML筆記

一、區塊元素

核心特性:

  • 獨佔一行：區塊元素預設會撐滿整個父容器的寬度（寬度 100%），其後的元素一定會被擠到下一行
  • 可設定尺寸：以直接在 CSS 中為它設定寬度 (width)、高度 (height)、上下外邊距 (margin) 與內邊距 (padding)
  • 可包含其他元素：裡面可以包其他的區塊元素或行內元素

二、行內元素

核心特性:

  • 不獨佔一行：行內元素的寬度由內容決定，且不會強制換行，除非遇到父容器邊界或使用了換行元素
  • 不可設定尺寸：無法直接設定寬度 (width) 與高度 (height)，但可以設定左右外邊距 (margin) 與內邊距 (padding)
  • 只能包含文本或其他行內元素：裡面只能包文本或其他的行內元素，不能包含區塊元素

三、網頁基本結構

  1. <!DOCTYPE html>宣告文件為 HTML5 版本，告知瀏覽器如何正確解析網頁
  2. <html lang="zh-TW">：指定語言為繁體中文。
  3. <head>：放置後台資料（元數據 Meta-data，如編碼、標題、外部樣式表連結），內容不會直接顯示在網頁的畫面上
  4. <meta charset="UTF-8">：設定網頁的字元編碼為 UTF-8，確保各國語言能正確顯示，避免出現亂碼
  5. <title>：定義網頁的標題，會顯示在瀏覽器的標籤上
  6. <link rel="stylesheet" href="style.css">：連結外部 CSS 樣式表，讓網頁能夠使用該樣式表中定義的樣式規則
  7. <body>：放置用戶所能看到的網頁主要內容（如文字、圖片、按鈕、影片等）

四、內容組織與格式

  1. <h1> ~ <h6>：區塊元素，分別表示不同層級的標題，數字越小表示字字體越大
  2. <p>：區塊元素，代表獨立的文字段落
  3. <strong>：行內元素，將文字加粗
  4. <em>：行內元素，將文字變斜體
  5. <code>：行內元素，表示程式碼片段，通常會使用等寬字體顯示
  6. <a href="URL">：行內元素，超連結，必須搭配 href 屬性指定目標網址，若要開新分頁可加上 target="_blank"
  7. <ul>：區塊元素，無序清單，項目開頭預設為圓點
  8. <ol>：區塊元素，有序清單，項目開頭預設為數字編號
  9. <li>：區塊元素，列表項目，清單中的個別項目，必須包在 <ul> 或 <ol> 之中
  10. <blockquote>：區塊元素，用於引述他人的長篇文字區塊，可用 cite 屬性標記來源網址
  11. <br>：單一標籤（不需閉合），用於強制換行
  12. <img src="路徑或網址" alt="描述">：行內區塊元素，單一標籤，用於在網頁中插入圖片，必須提供圖片來源和替代文字。
  13. <div>：區塊元素，劃分、組織網頁區塊或進行 CSS 排版，寬度預設會自動撐滿父容器的 100% 寬度
  14. <span>：行內元素，用於包裹文本或其他行內元素，常用於應用CSS樣式
  15. <class>：屬性，用於為元素指定一個或多個類別名稱，方便 CSS 選擇器選取和樣式應用

五、語意化標籤

  1. <header>：區塊元素，頁首，通常包含網站的 Logo、主要標題或主要導覽功能
  2. <nav>：區塊元素，導覽列，專門放置網站的主選單或連結區塊
  3. <main>：區塊元素，網頁的主要核心內容區域，一個頁面只能有一個，且不應包含重複的頁首尾資訊
  4. <section>：區塊元素，用於劃分主題相關的內容區域，可以包含標題和其他內容
  5. <footer>：區塊元素，頁尾，通常包含版權聲明、聯絡資訊或次要連結

CSS筆記

一、選擇器

  1. *：通用選擇器，選取頁面中的所有元素
  2. 元素選擇器：直接使用 HTML 標籤名稱來選取元素
    例如：p { color: red; } 將所有段落文字變紅
  3. 類別選擇器：使用 class 屬性定義的類別名稱來選取元素
    例如：.highlight h1 { background-color: yellow; } 將所有 class="highlight" 內的所有 h1 元素背景變黃
  4. 群組選擇器：同時選取多個不同的元素
    例如：h1, h2, h3 { margin-bottom: 20px; } 將所有標題元素的下方外邊距設為 20px
  5. :hover：偽類選擇器，當游標停在元素上方時觸發的效果
    例如：a:hover { color: red; } 將所有連結在滑鼠懸停時的文字變紅

二、相對單位

  1. px：絕對單位，表示像素，不隨瀏覽器視窗或字體大小改變
  2. vw：相對於瀏覽器視窗寬度的百分比
  3. vh：相對於瀏覽器視窗高度的百分比
  4. em：相對於目前元素的字體大小，若本身沒設定，則繼承父層
  5. %：相對於父元素的尺寸

三、尺寸屬性

  1. box-sizing： border-box：設定元素的尺寸計算方式為 border-box，即 width 和 height 包含 padding 和 border 代表整個元素的實際總寬高，
    防止元素被內邊距 padding 和邊框 border 撐大
  2. width：設定元素的寬度
    例如：.container { width: 100%; } 將 class="container" 的元素寬度設為 100%
  3. height：設定元素的高度
    例如：.box { height: 200px; } 將 class="box" 的元素高度設為 200px
  4. margin：外邊距，元素與其他元素之間的距離，也可加 -right 等來限定
    • margin: 10px 20px; 上下外邊距 10px，左右外邊距 20px
    • margin: 10px 20px 30px; 上外邊距 10px，左右外邊距 20px，下外邊距 30px
    • margin: 10px 20px 30px 40px; 上外邊距 10px，右外邊距 20px，下外邊距 30px，左外邊距 40px
  5. padding：內邊距，元素內容與元素邊框之間的內部留白，同 margin 的範例
    例如：.container { padding: 10px; } 將 class="container" 的元素內部內容與邊框之間的距離設為 10px
  6. border：邊框，圍繞元素的線條，可以設定寬度、樣式和顏色，solid 實線 、 dashed 虛線 、 dotted 點線
    例如：.box { border: 2px solid black; } 將 class="box" 的元素加上寬度為 2px、實線、黑色的邊框
  7. border-radius：邊框圓角，設定元素邊框的圓角程度
    例如：.box { border-radius: 10px; } 將 class="box" 的元素邊框設為 10px 的圓角

四、常用屬性

  1. color：設定文字顏色
    例如：p { color: blue; } 將段落文字變藍
  2. font-size：設定文字大小
    例如：h1 { font-size: 36px; } 將所有 h1 標題文字大小設為 36 像素
  3. font-weight：設定文字粗細
    例如：p { font-weight: bold; } 將段落文字設為粗體
  4. line-height：設定文字行高
    例如：p { line-height: 1.5; } 將段落文字的行高設為 1.5 倍
  5. text-decoration：設定文字裝飾
    • text-decoration: none; 移除底線
    • text-decoration: underline; 文字下方加底線
    • text-decoration: overline; 文字上方加線
    • text-decoration: line-through; 文字中間加刪除線
  6. text-align：設定文字對齊方式，left 左對齊、center 置中、right 右對齊
    例如：p { text-align: center; } 將段落文字置中對齊
  7. text-indent：設定文字首行縮排
    例如：p { text-indent: 2em; } 將段落首行縮排 2 倍字體大小
  8. background-color：設定元素背景顏色，也可使用色碼表或rgba表示
    例如：.container { background-color: lightgray; } 將 class="container" 的元素背景變淡灰色
  9. background-image：設定元素背景圖片，需寫出完整路徑
    例如：.hero { background-image: url("hero.jpg"); } 將 class="hero" 的元素背景設為 hero.jpg 圖片
  10. background-repeat：設定元素背景圖片的重複方式
    • background-repeat: repeat;（預設）背景圖片在水平和垂直方向上重複
    • background-repeat: no-repeat; 背景圖片不重複，只顯示一次
    • background-repeat: repeat-x; 背景圖片只在水平方向上重複
    • background-repeat: repeat-y; 背景圖片只在垂直方向上重複
  11. background-size：設定元素背景圖片的尺寸
    • background-size: auto;（預設）背景圖片保持原始尺寸
    • background-size: cover; 保持原圖比例縮放，讓圖片完全填滿整個區塊，超出區塊的部分會被裁切
    • background-size: contain; 持原圖比例縮放，讓整張圖片完整顯示在區塊內，可能會留下空白邊
    • background-size: 100% 100%; 強制將圖片拉伸到跟區塊一樣寬高，圖片會變形。
    • background-size: 200px auto; 寬200px，高度依比例調整
  12. background-position：設定元素背景圖片的位置
    • background-position: left top;（預設）背景圖片放在元素的左上角
    • background-position: center center; 背景圖片放在元素的正中央
    • background-position: right bottom; 背景圖片放在元素的右下角
    • background-position: 50px 100px; 背景圖片從元素的左上角開始，水平偏移 50px，垂直偏移 100px

五、佈局與定位

  1. display：設定元素的顯示類型
    • display: block; 轉為區塊元素，獨佔一行，寬度撐滿父容器
    • display: inline; 轉為行內元素，不獨佔一行，寬度由內容決定
    • display: inline-block; 轉為行內區塊元素，不獨佔一行，但可以設定寬高
    • display: none; 隱藏元素，該元素不會占據任何空間
    • display: flex; 轉為彈性容器
  2. position：設定元素的定位方式
    • position: static;（預設）元素按照正常文檔流排列，不受 top、left 等屬性影響
    • position: relative; 元素相對於其正常位置進行偏移，仍占據原來的位置空間，以 right、left、top、bottom 等屬性來移動
    • position: absolute; 元素相對於最近的已定位父元素進行偏移，不占據原來的位置空間，以 right、left、top、bottom 等屬性來移動
    • position: fixed; 元素相對於瀏覽器視窗固定位置，不隨滾動而移動
  3. Flexbox：彈性佈局，用於更靈活的元素排列，主軸變換後 justify-content 和 align-items 作用方向相反
    • display: flex; 將容器設為彈性容器，須放在父項對底下元素生效，預設呈水平排列
    • flex-direction: row;（預設）主軸為水平方向，元素從左到右排列
    • flex-direction: column; 主軸為垂直方向，元素從上到下排列
    • justify-content: center; 沿主軸將元素置中對齊
    • justify-content: space-between; 沿主軸將元素分散對齊
    • justify-content: space-around; 沿主軸將元素平均分布，兩端留一半的空間
    • justify-content: space-evenly; 沿主軸將元素平均分布，各元素間距相等
    • justify-content: flex-start; 沿主軸將元素靠左對齊
    • justify-content: flex-end; 沿主軸將元素靠右對齊
    • align-content: stretch; (預設) 沿垂直軸將元素拉伸以填滿容器
    • align-items: center; 沿垂直軸將元素置中對齊
    • align-items: flex-start; 沿垂直軸將元素靠上對齊
    • align-items: flex-end; 沿垂直軸將元素靠下對齊
