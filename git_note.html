Git筆記

Git是一個分散式版本控制系統，主要用於協助開發者管理和追蹤程式碼的變更。以下是一些基本的Git指令和概念：

一、 環境設定與初始化

  1. git --version：檢查電腦中是否已成功安裝 Git 及其版本編號
  2. git config --global user.name "姓名"：設定Git的使用者名稱。
  3. git config --global user.email "郵件地址"：設定Git的使用者郵件地址。
  4. git init：初始化一個新的Git倉庫。

二、 本地檔案狀態管理

  1. git status：檢查當前目錄中每個檔案的狀態（如：未追蹤、已修改或準備提交）
  2. git add <檔案名稱>：將特定檔案由「未追蹤」或「已修改」狀態加入到暫存區，準備拍攝快照
  3. git add .（或使用萬用字元如 *.md）：將當前目錄中所有變更（包含新增、修改與刪除）一次全部加入暫存區
  4. git commit -m "訊息"：為暫存區內的檔案拍攝快照並建立一個新的版本紀錄，必須附帶簡短的說明訊息

三、 瀏覽紀錄與版本比較

  1. git log：列出完整的提交歷史，包含作者、日期、ID 編號與說明文字
  2. git log --oneline：簡化版的提交歷史，每筆紀錄僅顯示一行，適合快速瀏覽
  3. git diff <還原點ID> <檔案名稱>：比較目前版本與特定歷史版本之間的內容差異

四、 版本還原

  1. git checkout <還原點ID> <檔案名稱>：將特定的檔案還原到先前的某個狀態，這是一種保留歷史記錄的安全做法
  2. git reset --hard <還原點ID>：將整個專案強制還原到指定的提交點，並捨棄該點之後的所有變更紀錄（此操作不可逆）

五、 遠端協作 (GitHub)

  1. git push：將本地的提交推送到GitHub等遠端倉庫
  2. git pull：從遠端倉庫獲取最新的變更並合併到本地分支。
  3. git clone <網址>：將 GitHub 上的遠端儲存庫完整複製到本地端電腦
  4. git checkout -b <分支名稱>：建立一個新的分支並立即切換過去，讓開發者可以在獨立的線路中嘗試新功能而不影響主線
