Unity筆記

一、預設函式與宣告

  1. public class 腳本名稱 : MonoBehaviour：定義一個繼承自 MonoBehaviour 的類別，這是 Unity 中腳本的基本結構
  2. Start()：預設函式，在遊戲開始時執行一次，用於初始化設定
  3. Update()：預設函式，每幀更新時執行，用於處理遊戲邏輯和玩家輸入
  4. using：引入命名空間，方便使用其中的類別和函式
    • using UnityEngine;：引入 Unity 引擎的核心命名空間，包含了大部分的遊戲開發功能
    • using UnityEngine.InputSystem;：引入 UnityEngine.InputSystem 命名空間，用於處理玩家輸入
    • using UnityEngine.UI;：引入 UnityEngine.UI 命名空間，提供了 UI 元件如 Button、Text 等
    • using UnityEngine.SceneManagement;：引入 UnityEngine.SceneManagement 命名空間，用於場景管理

二、物件與元件尋找

  1. GameObject.FindGameObjectWithTag("Tag名稱")：根據標籤尋找遊戲物件，通常放在Start()裡面
  2. GetComponent<元件名稱>()：取得物件上的指定元件
  3. 變數 = GameObject.FindGameObjectWithTag("Tag名稱").GetComponent>元件名稱>();:通常放在Strat()裡面用來找物件的腳本存入變數，腳本無法用拖曳的
  4. 物件.transform.Find("子物件名稱")：在物件的子層級中尋找指定名稱的子物件，可用 transform 宣告的變數來儲存
  5. public:公開變數，可在 Unity 檢測器（Inspector）中直接修改數值，或讓其他腳本存取
    • public GameObject 變數名稱;：定義一個公開的 GameObject 變數，可以直接將遊戲物件拖曳到inspector中
    • public 元件名稱 變數名稱;：可利用此變數存入物件的腳本，或是將其他元件拖入其中
  6. private:私有變數，僅限於該腳本內部使用，無法在inpector中修改或被其他腳本存取
  7. [SerializeField]:序列化私有變數，可以在inspector中修改數值，但仍是私有的，其他腳本無法存取

三、時間與隨機性

  1. Time.deltaTime：取得上一幀到目前幀的時間間隔，常用於計算移動速度或延遲
  2. Random.Range(min, max)：產生指定範圍內的隨機數字

四、移動機制

  1. transform.position：物件的位置屬性，可以直接修改來移動物件
    • transform.position += Vector3.right * speed * Time.deltaTime;：將物件沿右方向移動，速度為 speed，乘上Time.deltaTime避免電腦性能影響
    • transform.position = new Vector3(x, y, z);：直接設定物件的位置為指定的座標
  2. 變數名稱.linearVelocity：設定或取得剛體的線性速度，需要有裝 RigidBody2D 才能使用
    • 變數名稱.linearVelocity = new Vector2(xSpeed, ySpeed);：設定剛體的水平速度為 xSpeed，垂直速度為 ySpeed
    • 變數名稱.linearVelocity += Vector2.up * jumpForce;：在原有速度基礎上增加一個向上的跳躍力

五、碰撞與觸發

  1. OnCollisionEnter2D(Collision2D collision)：當兩個實體阻擋（非 Is Trigger）的碰撞體接觸時自動觸發，碰撞物將傳入 collision 參數
  2. OnTriggerEnter2D(Collider2D other)：當其中一個碰撞體勾選了 Is Trigger（觸發器），兩者穿透時自動觸發，碰撞物將傳入 other 參數
  3. 傳入參數名稱.CompareTag("Tag名稱")：檢查碰撞物件是否具有指定標籤
  4. 傳入參數名稱.gameObject.layer == 3：檢查撞到的物件是否屬於特定圖層，通常用於區分背景、玩家或特定界線

六、物件控制

  1. Instantiate(prefab物件, 位置, 旋轉)：在指定的位置和角度，生成一個預製物（Prefab）
    例如：Instantiate(pipeArray[randomPipe], new Vector3(transform.position.x, Random.Range(lowestPoint, highestPoint), 0), transform.rotation);
  2. Destroy(物件)：銷毀一個物件，使其從遊戲中移除
  3. 物件.SetActive(true/false)：控制物件的顯示與隱藏

七、輸入控制

  1. Keyboard.current.spaceKey.wasPressedThisFrame：檢測空格鍵是否在當前幀被按下
  2. Mouse.current.leftButton.wasPressedThisFrame：檢測滑鼠左鍵是否在當前幀被按下

八、場景管理

  1. SceneManager.LoadScene("場景名稱")：載入指定名稱的場景，通常用於重新開始遊戲或切換關卡
  2. SceneManager.GetActiveScene().name：取得目前活動場景的名稱

九、UI控制

  1. Text宣告的變數.text：設定或取得 UI Text 元件的文字內容
  2. 變數.ToString("F1")：將變數的值轉為字串並保留小數點後第一位，若括號內空白則完整保留原數值

十、本地存檔

  1. PlayerPrefs.SetInt("Key", 數值)：將整數值儲存到本地存檔中
  2. PlayerPrefs.GetFloat("Key", 預設值)：從本地存檔中讀取浮點數值，若不存在則返回預設值

十一、除錯與測試

  1. Debug.Log(訊息)：在控制台輸出訊息，用於除錯
  2. [ContextMenu("函數名稱")]：在腳本右上角的三個點選單中，點選就能在非執行狀態下直接觸發該函數
